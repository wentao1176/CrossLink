源码提交：5009205be86b566283fdd9ce659c5412f4ab5ff4。Windows 与 Android 的 QA/production 包从这个提交构建；发布签名和文件校验已通过；实机、公网和持续使用门槛仍待完成。

## 使用方式

Windows 双击 setup.exe 安装，Android 安装 ARM64 release APK。日常使用仅登录同一账号，平台地址已内置，设备自动出现；注册额外填写邮箱。文字、链接、文件通过平台中转。设置中开启“复制粘贴同步”后同步文字/链接，可随时暂停同步而保留登录。

Android 从其他 App 复制后需要打开 CrossLink 才能读取本机新复制内容，这是[Android10起的焦点读取限制](https://developer.android.com/about/versions/10/privacy/changes#clipboard-data)；远端剪贴板也在 CrossLink 获得焦点后写入，再切到目标 App 粘贴。图片/文件剪贴板格式、跨 App 后台读取、强行停止后的持续接收不在已验证范围。普通文件传输上限100MiB，保留7天，尚无分块续传。

生产服务尚未开放公网；当前 production 包可安装，但外部网络登录和互传要等后续开放入口。QA 包仅用于已有 SSH 凭据的开发验收通道；普通用户无需设置地址、端口或 SSH。

## 审查与决定

一次最终只读审查无Critical。Important备份容量检查改为估算有效附件、数据库、私密材料与压缩余量，流式写入继续保留系统余量；两项失败回归修复后全套55项通过。实际Windows二进制依赖发现CRT缺失，经重新分级为Important，包内补齐微软签名运行库并真实加载验证。按一次修复约定未再复审。

已知Minor：Android13及以上通知权限状态文字仅在初始化读取，系统设置授权/撤权后需重新启动App后刷新；实际接收逻辑不依赖这个显示文字，手机行为仍待验收。

发布构建故障按证据处理：Android AOT因导入桌面FFI失败，改用独立Windows入口且保留依赖/SDK锁定；Windows缺ATL和UTF8编译选项分别补齐；无符号链接权限时只在.build内建立目录junction；服务器未加内存或修改其他服务，APK维持850MiB/2800MiB内存加swap上限。一次未受限的诊断Java触发OOM，之后仅使用受控构建。安卓发布lint只补显式includeSubdomains=false，没有关闭检查或加入忽略基线。

所有裁决与测试路径保留在交付执行ledger中。源码仍在服务器feat/mvp分支，未推送或合并。

## 安装/运维边界

Android release使用专用RSA3072签名身份，私钥不在包、源码导出或公开清单中；后续升级必须使用同一身份并提高版本号。旧0.2开发签名与0.3正式签名不同，旧调试版不能原地升级，先保留已下载文件；QA可以并行安装。

Windows安装只需当前用户，CRT随包提供；CrossLink发布者Authenticode证书尚未配置。程序退出/卸载与全局暂停是独立操作，关闭窗口可常驻托盘，真实通知/重启行为仍待验收。

备份位于/home/CrossLink/backups，同盘备份不能覆盖整台服务器丢失；异机灾备目标尚未提供。公开网关配置和回退方案已准备，未经明确授权不启用。
